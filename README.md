# Sirius 과제 부스 3D

도면 위치 그대로 둔 부스입니다. 구조, TV, 모니터 위치는 고정이고, 오른쪽 입간판과 하드웨어 구성을 바꿔 링크를 보내 논의합니다.

공개 주소: https://sung-park.github.io/sirius-clab-fair-3d-booth/

## 도면에서 가져온 치수

- 폭 2.25 m, 모듈 0.75 m × 3
- 전체 깊이 0.75 m, 높이 2.25 m
- 하부 선반 높이 1.00 m, 선반 깊이 0.50 m
- 상단 그래픽 2,250 × 300 mm
- 55″ 터치 TV는 16:9 실치수(약 1.22 × 0.69 m)
- 32″ 모니터는 도면처럼 세로가 기본

배치는 평면도 기준 한 가지입니다. 화면은 뒤쪽 월에 있고 선반은 앞으로 0.50 m 나옵니다. 55″는 왼쪽 두 모듈, 32″ 모니터는 왼쪽 세로로 고정입니다. 오른쪽 벽은 트래커 하드웨어 구성이고, 그 아래는 시료 비교입니다. 도면의 주황 상자는 마감색이 아니라 위치 표시라서, `마크업`을 켰을 때만 나타납니다. 배경은 아이보리 벽과 카펫이 있는 큰 컨퍼런스 룸입니다.

## 로컬에서 보기

```bash
npm install
npm run dev
```

`npm run check`는 치수, 패널이 겹치지 않는지, 측면·평면 카메라 방향을 확인합니다.

## 조작

- 드래그로 회전, 스크롤로 줌, 우클릭으로 이동
- 폰에서는 한 손가락으로 돌리고, 두 손가락으로 확대하고 이동합니다. 세로 화면의 처음 시점은 사람과 입간판이 같이 들어오게 물러나 있습니다.
- 아래 바에서 3/4, 정면, 측면, 평면, 관람 시점
- `D` 치수, `M` 도면 마크업, `H` 패널 숨김
- 오른쪽에서는 입간판과 하드웨어 구성을 바꿉니다. 부스 구조와 모니터 위치는 도면 그대로입니다.
- 입간판은 부스 오른쪽의 세로 1개판입니다. 파트너의 목소리와 사용자의 목소리 두 포스터를 바꾸며, 둘 다 원본 비율을 유지합니다. 도면에는 없는 추가 홍보물입니다.
- 하드웨어 구성은 아크릴 판이 기본입니다. 같은 자리에서 벽에 붙인 인쇄물로 바꿀 수 있고, 인쇄물은 원본 784 × 1168 비율을 유지합니다.
- 메모를 적고 `이 구성 링크 복사`를 누르면 그 구성과 카메라가 링크에 실림

화면 속 호흡수와 활동 수치는 배치를 보기 위한 예시입니다.
